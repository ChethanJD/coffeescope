# Contributing to CoffeeScope

Thanks for your interest in contributing! Here's how to get started.

## Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/coffeescope.git
   cd coffeescope
   npm install
   ```
3. Create a new branch for your change:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development Workflow

- Run the dev server: `npm run dev`
- Check types before committing: `npm run type-check`
- Lint your code: `npm run lint`

## Commit Guidelines

- Write clear, descriptive commit messages
- Keep commits focused on a single change where possible

## Submitting a Pull Request

1. Push your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
2. Open a pull request against the `main` branch of this repo
3. Describe what your change does and why
4. Link any related issues

## Reporting Bugs / Requesting Features

Please open an issue with:
- A clear description of the bug or feature
- Steps to reproduce (for bugs)
- Screenshots, if relevant

## Code of Conduct

Be respectful and constructive. We want CoffeeScope to be a welcoming project for everyone.
